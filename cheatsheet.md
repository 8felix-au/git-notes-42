# Git Quick Reference Cheatsheet

A collection of useful Git commands for daily development work.

## Setup and Initialization
- Initialize a local repository: `git init`
- Clone a remote repository: `git clone <url>`

## Staging and Committing
- Check repo status: `git status`
- Add files to staging area: `git add <filename>` or `git add .`
- Commit staged changes: `git commit -m "commit message"`

## Branching
- List branches: `git branch`
- Create branch: `git branch <name>`
- Switch branch: `git checkout <name>`
- Create and switch: `git checkout -b <name>`
